Remember the page.
Refresh on repeat.

Auto Refresh Cache remembers an exact page’s refresh interval. Set Minutes and Seconds, allow access to that site, and start an independent timer for each matching tab.

Start a timer

  1. Pin Auto Refresh Cache through Chrome’s Extensions menu, then open a normal HTTP or HTTPS page.
  2. Click the teal refresh icon. Enter whole numbers in both Minutes and Seconds and choose Start. The default is 10 minutes, 0 seconds. Totals must be at least one second.
  3. Allow access to the current site when Chrome asks. Only saved exact-page URLs receive timers.
  4. Close the popup. The green toolbar badge shows total seconds remaining; hover to read the full number.

Pause, resume and clear

Stop this tab pauses only this tab. Resume starts a fresh interval there. Changing a saved interval restarts running tabs at that exact URL; paused peers stay paused. Clear auto refresh removes that page’s rule and timers in all tabs. Clear does not revoke Chrome’s site permission; manage it separately in the extension’s Site access settings.

What is remembered

Saved page URLs and intervals stay on this device across browser restarts. Fragments such as #chat are ignored; different paths, queries, query order and trailing slashes can identify different pages. Opening the same saved page in another tab starts its own full interval.

Tab pauses survive page reloads and navigation away/back, but Chrome clears them on browser restart or extension reload, update or disable. Saved rules remain and can start timers again.

Timing and limitations

Chrome may delay refreshes and badge updates in background tabs, sleeping devices or discarded pages. A countdown at zero means a refresh is due. Intervals under 30 seconds use a page timer; longer intervals use Chrome alarms. Missed refreshes are not replayed in bursts. Chrome internal pages and other restricted pages are unsupported.

Like a manual reload, an automatic refresh can discard unsaved page input. Stop the timer while editing.

Privacy and removal

The extension stores exact page URLs and refresh settings locally and uses temporary tab state. No analytics, advertising, account or publisher backend is included. Refreshes still load the destination website normally. Read the privacy policy for the complete data handling description.

Use Clear to delete a saved rule. Remove the extension in chrome://extensions to delete all of its stored settings. For an unpacked update, reload the extension and any already-open pages.

Get support

Report a reproducible issue on GitHub with your Chrome version, interval and what happened. Issues are public: omit private URLs, credentials and other sensitive information. The source code is available for inspection.
